# Paper Stage — 桌面软件产品发布页设计法

一套从成熟产品站逆向拆出的设计体系。核心不是"好看"，而是**让一个技术产品看起来诚实、可靠、且已经做好了**。

## 一、这套体系的三个支点

### 1. 纸 · 墨 · 一点红
- 底色是**暖白纸** `#F8F9F6`，不是纯白。纯白显廉价、显模板。
- 正文是**带绿调的近黑** `#222B29`，不是 `#000`。它比纯黑柔，和暖底同温。
- **全站只有一个彩色强调**：陶土红 `#DF503C`。只出现在：品牌名后的句点、大标题里的一个词、CTA 按钮、图标、链接 hover。
- 绿色 `#41805F` 是**功能性**的（对勾、运行状态），不是装饰色。
- 禁止：渐变、玻璃拟态、霓虹光晕、彩色阴影、多色图标组。

### 2. 舞台（Stage）—— 这套风格最值钱的一个零件
所有产品界面示意图不裸放，而是装进一个**舞台容器**：
```
容器: 暖米色底 #EFEAE2 · 圆角 22 · 高度约 476 · overflow hidden
  ├─ 极淡同心圆轨道: 1px 描边 #D7CFC2, 直径 490 / 610, 偏移出画面
  ├─ 左上角单等宽标签: "JETTY / STAGE 01", 9px, 字距 1.4px, 色 #716F61
  ├─ 一张轻微倾斜(-3deg)的白色窗口: 圆角 11, 细边 #fff,
  │    阴影 0 20px 38px -17px #5f554745 + 0 2px 7px #5f554719
  │    窗口里是**手绘感的真实界面**（不是灰框占位）
  ├─ 一个柔和的色块圆: 直径 280, 色 #D4D9B7, 透明度 .65, 溢出右上角
  └─ 底部居中 11px 图注: "产品界面示意"
```
要点：
- 插图**用结构画出来**，不用截图、不用 AI 生成图。用 div/图层搭出侧栏、列表、状态点、代码片段。
- 舞台背景永远比页面底色**更暖更深一点**，形成"取景框"感。
- 轨道圆和色块圆是**气氛**，不是装饰，要淡到几乎看不见。

### 3. 反营销的语气
文案可信度来自**具体**，不来自形容词：
- 版本号写全：`v0.3.3.11 · Apple Silicon · macOS 26 或更新`
- 资源限制写死：`每台最多 2 核 / 6 GB / 64 GB，不支持 SD`
- 主动写缺点：`当前安装包不含系统镜像`、`不保证全部兼容`
- 价格写原价与折扣：`¥9.9 / 月` + `正价 ¥19.9 / 月`
- 小字声明：`一次性付款，不自动续费`、`资源额度是上限，实际分配受限制`

这套"工程诚实"是整个页面最高级的信任装置。**不要改成营销话术。**

## 二、设计令牌（直接复制）

```css
:root {
  color-scheme: light;
  /* 面色 */
  --bg: #f8f9f6;            /* 页面底 · 暖白纸 */
  --surface: #ffffff;       /* 卡片/白色区块 */
  --surface-soft: #f0f2ed;  /* 次级底 */
  /* 墨色 */
  --ink: #222b29;           /* 标题/正文 */
  --muted: #707873;         /* 辅助正文 */
  --subtle: #858c86;        /* 最弱信息 */
  --line: #e1e5dd;          /* 1px 分隔线 · 全站唯一分割手段 */
  /* 强调 */
  --accent: #df503c;
  --accent-hover: #c5402e;
  --green: #41805f;         /* 仅功能性 */
  /* 舞台 */
  --stage: #efeae2;
  --stage-line: #d7cfc2;
  /* 尺度 */
  --radius: 22px;
  --max-width: 1180px;
  --nav-height: 80px;
}

/* 暗色是可选的，只做反色，不改关系 */
[data-theme="dark"] {
  --bg: #171c1a;  --surface: #202723;      --surface-soft: #252d27;
  --ink: #f0f2ea; --muted: #acb5ab;        --subtle: #99a396;
  --line: #364036; --accent: #ff8a73;      --accent-hover: #ffa18d;
  --green: #9bc3a4; --stage: #373c33;      --stage-line: #5b6250;
}
```

### 字号与字重（体系的关键在"紧"）
| 角色 | 规格 |
|---|---|
| 字体族 | 系统栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif` — **不引外部字体**，这本身就是"原生桌面软件"的暗示 |
| H1 | `clamp(40px, 4.45vw, 64px)` / lh **1.25** / **letter-spacing −2.6px** / weight **650** |
| H1 强调词 | 同尺寸，色 = accent，weight 600，字距 −3px |
| H2 | `clamp(29px, 3.1vw, 40px)` / lh 1.35 / ls −1.25px |
| H3（能力标题） | 29px / lh 1.4 / ls −0.8px |
| H3（卡片标题） | 21px / ls −0.4px |
| 正文 | 15–16px / lh **1.85–1.95** / 色 muted |
| 按钮 | 14px / weight 600 |
| 元信息 | 10–12px / 常规字距 |
| 等宽标签 | `ui-monospace, SFMono-Regular, monospace` 9–11px / 字距 1.4px / 全大写 |

**负字距是这个风格的第二签名。** 中文标题也要给负字距（−1 ~ −3px），会立刻从"网页"变成"软件官网"。

### 圆角与阴影的尺度差
- 大容器 22 / 图版 20 / 窗口模拟 11 / 按钮 9 / 小标签 6
- **全站唯一的阴影**只给舞台里那张倾斜窗口。其他一律用 `1px solid var(--line)` 分隔，不用阴影、不用卡片堆叠。

## 三、页面骨架（10 个区块，固定顺序）

1. **导航** — 固定顶栏，不透明（不要 backdrop-blur，滚动会重绘）。高 80，底部 1px 线。品牌 `Name` + 红色句点。右侧：链接 13px muted → hover 变 accent，主题切换图标按钮，主 CTA（最小高 39 的小号按钮）。
2. **首屏 Hero** — 两栏 `.95fr / 1.05fr`，gap 40，`padding-top 66 / bottom 60`。
   - 左：版本 chip（1px 边框 + 6px 绿色状态点 + 11px 文字）→ H1 → 描述（16px / lh 1.9 / max-width 460）→ 双 CTA（主：accent 实心；次：透明 + 1px 边）→ 10–12px 系统要求小字 → 三个 tiny-check（13px 绿勾 + 11px 文字）
   - 右：舞台插图
3. **基石条** — 白底，上下 1px 线，4 列等分，`padding-block 27`，gap 27。每列：绿色线性图标 25px + 标题 14px/600 + 说明 12px muted。**这是最低成本建立信任的区块，别省。**
4. **使用场景** — 3 列，`gap 42`，第 2/3 列 `border-left: 1px` + `padding-left: 34`。每列：红色图标 27px → H3 21px → 正文 15px/1.9。
5. **核心能力（两行交替图文）** — 白底区块，上下 1px 线，`padding-block 78`。
   - 行：`grid 1.13fr 1fr` / gap 70 / 交替 `reverse`
   - 文案侧：H3 29px → 正文 15px/1.9 → 无列表符号的特性清单（15px 绿勾 + 14px 文字）
   - 图版侧：暖色图版，圆角 20，`1px solid var(--stage-line)`，底图 11px 居中图注
   - 两行之间 `padding-top 76`
6. **定价** — 3 张卡：Free / 月订阅 / 年订阅。折扣价用大字号 + 原价划线小字 + "每月省 ¥X" 小标签。卡下方小字说明支付方式与续费规则（**必须写"不自动续费"**）。再给一个"详细对比"折叠入口。
7. **上手三步 + 系统要求** — 左侧 1-2-3 步骤（40px 圆形序号，1px 边框，数字用 accent）；右侧"系统要求"表（项目名 muted 小字 / 值 ink）。
8. **FAQ** — H2 + 6 条问答。问题用 17px/600，答案 15px/1.9 muted。**问的必须是真异议**（能不能离线？和其它方案差别？兼容性？退款？）。
9. **结尾 CTA** — 短促 H2 + 一个按钮 + 一行信任小字。
10. **页脚** — `1.7fr 1fr 1fr 1fr` 四列（品牌列 + 3 组链接），底部 legal 条：上 1px 线，11px muted，两端对齐。

### 节奏规则
- 每段正文 `padding-block` 在 **78 / 86px** 两档之间轮换，不要都用一个值。
- 文字密集区之后必须紧跟一个**视觉区块**（舞台 / 图版 / 定价卡），不许连续三段纯文字。
- 分隔靠 `1px --line` 和留白，绝不靠背景色块堆叠。全站只有 1–2 处白底区块用于切分。

## 四、文案写法

**H1 公式**：`把 X，[动词]你的 [Y]。` 且 Y 用强调色。
- `让 Android，住进你的 Mac。`
- `让 API 调试，回到你的 Mac。`

**用法**：动宾短句 + 第二行给机制。
- 副标题：`在 Mac 上运行独立的 Android 设备。安装应用、管理设备，让移动端的工作回到桌面。`

**区块标题**：一句人话，带句号。
- `让 Android，融入你的工作方式。` / `熟悉的 Mac，更多能做的事。` / `先免费体验，再选择所需。`

**禁止**：赋能、一站式、极致、颠覆、AI 驱动、无缝、全新升级、🚀。任何感叹号。

## 五、执行清单

- [ ] 底色是暖白而非纯白；正文是墨绿黑而非纯黑
- [ ] 全站只有一个彩色强调色，且只用在 4 类位置
- [ ] H1 有负字距（−2.6px 量级），且含一个强调色词
- [ ] 至少一个"舞台"插图，带轨道圆 + 等宽角标 + 底部图注
- [ ] 舞台里的界面是**画出来的**，有真实的状态点、配置数字、文件行
- [ ] 全站没有渐变、玻璃、霓虹、彩色阴影
- [ ] 唯一的阴影在舞台窗口上
- [ ] 分割全靠 1px 线，不靠色块
- [ ] 有基石条（4 列信任条）
- [ ] 定价区写了原价、折扣、节省额、支付方式、"不自动续费"
- [ ] 文案里有 3 处以上"主动说缺点"的具体限制
- [ ] 页脚有 legal 条
- [ ] 字重最高 650–750，不要 800/900

## 六、常见跑偏

| 跑偏 | 修正 |
|---|---|
| 用大字号渐变标题 | 回退成纯 accent 色的单个词 |
| 把舞台插图换成灰色占位框 | 必须画出真实界面结构 |
| 加了一堆卡片 + 阴影 | 改成 1px 线 + 列分隔 |
| 强调色扩散到图标、背景、标签 | 收回，只留 4 处 |
| 文案开始吹 | 换成版本号、资源上限、兼容性说明 |
| 全站一个 padding 值 | 78/86 轮换，hero 66/60 |
