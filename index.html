How it works

它做的事，不止生成字幕。

从发现缺字幕，到把成品挂回播放器，SubNow 都在后台完成。你只需要决定这一次要不要生成。

不打扰，
只在缺字幕时出现。

SubNow 常驻菜单栏，每 3 秒检查一次正在播放的 mpv / IINA。连续两轮确认缺中文字幕，才会发系统通知；组件没准备好时只提示，不会启动流水线。

  • IPC 可用时精确读取字幕轨，不靠猜
  • 没有 IPC 时用 ffprobe 与同名文件兜底
  • 「忽略本次」的视频不再重复提醒

先让你看上，再慢慢变好。

确认后自动分阶段：提取音频、本机转录、挂载原文，再翻译成双语粗稿；需要时后台用 large-v3 重做，完成后热替换。播放不中断。

  • 中文在上、原文在下，ASS 样式 56 / 38 号
  • 同一磁盘正在播放时，提取自动暂停让路
  • 并发上限 1，新打开的视频优先处理

Install / 3 steps

三步开始。

安装包不大，主要时间花在第一次的模型下载上。下载支持断点续传，失败会自动回退镜像。

  1. 1

    安装应用

    用 Homebrew 安装，或从 GitHub Releases 下载 DMG。手动安装若被 Gatekeeper 拦截，按常见问题里的命令移除隔离标记。

    brew install --cask etng/taps/subnow
  2. 2

    准备组件

    首次启动会打开组件就绪检查。语音模型约 1.5 GB，ffmpeg 缺失时会给出 brew 命令。全部就绪后，菜单栏显示「就绪」。

  3. 3

    照常播放

    用 mpv 或 IINA 打开视频。收到「没有中文字幕」的通知后点「生成字幕」，进度会显示在菜单栏和播放器左上角。

    想让字幕在播放中直接挂载，可在 IINA 高级设置里开启 IPC；不配置也能在下次播放时自动加载。

FAQ

常见问题。

如果下面没有你想问的，可以在 GitHub Issues 里提。

视频会上传吗？

转录和本地翻译都在本机完成。只有你选择 OpenAI 兼容 API 时，字幕文本会发送到你填写的服务；视频本身不会上传。

必须配置 IINA 的 IPC 吗？

不是必须。配置后可以精确判断字幕轨，并在播放过程中直接热挂载；不配置也能用，字幕会生成在视频旁边，下次播放自动加载。

为什么不支持 Intel Mac 和 VLC？

目前只支持 Apple Silicon 和 macOS 14 以上，依靠 Metal 做转录加速；播放器只覆盖 mpv 与 IINA。VLC、QuickTime 和 Intel Mac 暂不支持。

「精做版」和粗稿差在哪？

粗稿用 large-v3-turbo，几分钟内可看；精做版用 large-v3 重新转录和翻译，更慢。开启自动精做后，完成会热替换；关闭就保留粗稿。

首次启动为什么要下载模型？

语音模型约 1.5 GB，不随安装包分发。首次启动从 HuggingFace 下载，失败会自动回退镜像，支持断点续传；本机已有模型可以直接复用。

被 Gatekeeper 拦了怎么办？

安装包是 ad-hoc 签名、未公证。用 brew 安装会自动移除隔离标记；手动下载 DMG 被拦截时，执行 xattr -dr com.apple.quarantine /Applications/SubNow.app。
